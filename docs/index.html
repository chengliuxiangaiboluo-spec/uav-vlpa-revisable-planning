MULTIMODAL UAV MISSION PLANNING

A revisable interface from instruction to execution.

UAV-VLPA links heterogeneous operator inputs to hierarchical task structure and map-feasible planning, while retaining a clear boundary between offline visual grounding and online replanning.

Explore the framework ↓ View audited code ↗

RESEARCH SCOPE

01

Text, voice, gesture, and map annotation inputs.

02

Hierarchical task decomposition with constrained transitions.

03

Map-level planning conditioned on structural availability.

FRAMEWORK

Three layers, one revisable interface.

The interface carries the fused representation to task decomposition and the structural-availability signal to planning. Cached visual grounding is prepared offline rather than represented as zero-cost online inference.

01

Online multimodal understanding

Modality-gated cross-modal attention fuses operator inputs into a shared representation.

02

Task decomposition and replanning

HSATD produces ordered atomic tasks; AADR uses the structural signal to condition obstacle avoidance and replanning.

03

Offline preparation

Frozen Molmo grounding predicts map coordinates before execution; cached predictions are distinct from online planning latency.

REPRODUCIBILITY

Code is public. Controlled assets remain controlled.

The release includes source modules, strict experiment runners, aggregation utilities, and a portable integrity check. Exact numerical re-evaluation requires authorized benchmark data, split manifests, model caches, and seed checkpoints.
